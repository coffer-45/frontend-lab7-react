## Локальний запуск

Потрібні Node.js 20.19+ або 22.12+ та npm. У каталозі `Lab7/`:

```sh
npm ci
npm run dev
```

Відкрийте адресу, показану Vite у терміналі. Для підготовки статичної версії виконайте `npm run build`: готові файли збираються в `docs/`. Саме з `main/docs` розміщено GitHub Pages. `node_modules/` не комітиться; код і `package-lock.json` доступні в репозиторії. Методичка на с. 41 PDF показує `create-react-app` як приклад, але тут використано актуальний збирач Vite з тим самим React.

## Завдання 1 — ЛР №4 у React

- `src/components/Header.jsx` — **функціональний** компонент навігації;
- `src/components/Content.jsx` — **класовий** компонент з інформацією зі сторінки ЛР №4 та власним станом;
- `src/components/Image.jsx` — **функціональний** компонент фото, що отримує властивості через `props`.

Клік по картках **№8 і №9** перемикає фон і колір тексту, повторний клік повертає їх назад. Кнопки під фото додають, збільшують, зменшують і видаляють зображення; після видалення всіх фото можна додати їх знову. На відміну від імперативної ЛР №4, тут зміни інтерфейсу здійснюються через `setState()` та повторний рендер React, а не ручні зміни DOM. Оригінальний репозиторій ЛР №4 не змінювався.
